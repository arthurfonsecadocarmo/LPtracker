# LPtracker

Rastreador de preços que avisa no Telegram quando um produto atinge o menor
preço à vista dos últimos 90 dias.

## Status
Em desenvolvimento (fatia 1: coleta contínua de 1 produto).

## Requisitos
- Python 3.14
- `pip install -r requirements.txt`
